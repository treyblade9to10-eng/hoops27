# HOOPS 27

A 3D NBA basketball game for the browser: real 2026-27 rosters and overalls, Play Now (any two teams, 5v5 or 3v3),
a timing shot meter, layups, dunks, alley-oops, dribble moves, broadcast camera, and a MyTEAM card mode (coins are
earned by playing only).

Credits: player bodies and animations are CC0 assets by Quaternius (Universal Base Characters, Universal Animation
Library 1 + 2). 3D engine: three.js (MIT). Crowd recordings: see audio/CREDITS.txt. Team logos and player headshots
load from ESPN. Not affiliated with the NBA or 2K.
